# Закупівлі Prozorro — моніторинг для лікарні

Android-додаток для стеження за закупівлями КНП «Третя черкаська міська лікарня швидкої медичної допомоги» (ЄДРПОУ **05503705**) у системі Prozorro. Код ЄДРПОУ змінюється в налаштуваннях, можна вказати кілька замовників.

## Що вміє

- **Закупівлі**: усі процедури замовника, нові зверху. Фільтри за статусом (активні, усі, завершені, невдалі) і типом (конкурентні, звіти, переговорні), пошук за назвою або кодом ДК 021. Якщо ввести номер `UA-…`, відкриється картка закупівлі.
- **Картка закупівлі**:
  - строки і відлік часу до кінця подання;
  - предмет закупівлі, лоти;
  - пропозиції учасників, кваліфікація та переможці, договори;
  - питання (окремо видно ті, що без відповіді), скарги й вимоги, відміна;
  - документи (відкриваються в браузері);
  - індикатори ризиків ДАСУ і моніторинги.
- **★ Відстеження**: закупівлі з зірочкою перевіряються окремо, сповіщення приходить про будь-яку зміну: нове питання, скаргу, зміну статусу, підписання договору.
- **Сповіщення у фоні**: нові закупівлі замовника і зміни статусу. Інтервал перевірки від 1 до 24 год, плюс кнопка «Перевірити зараз».
- **Ризики**: перелік процедур замовника, у яких спрацювали індикатори ризиків Державної аудиторської служби.

Додаток лише **читає відкриті дані** і нічого не надсилає від імені лікарні. Обліковий запис і ключі API не потрібні.

## Як отримати APK

### Варіант 1. GitHub, без встановлення програм (рекомендовано)
1. Створіть на github.com новий репозиторій, наприклад `prozorro-monitor`; він може бути приватним.
2. Завантажте в нього вміст цієї папки (кнопка **Add file → Upload files**; зверніть увагу, щоб завантажилась і прихована папка `.github`). Можна також попросити Claude зробити це, якщо дати йому доступ до репозиторію.
3. Збірка запуститься автоматично (вкладка **Actions**, приблизно 4–6 хв).
4. Готовий файл буде у вкладці **Releases** → `prozorro-monitor-N.apk`. Відкрийте цю сторінку з телефона і завантажте APK.

### Варіант 2. Android Studio
1. Відкрийте папку проєкту в Android Studio (File → Open).
2. Дочекайтесь синхронізації Gradle.
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**. Файл з'явиться в `app/build/outputs/apk/`.
   Або підключіть телефон кабелем і натисніть ▶ Run.

### Встановлення на телефон
Відкрийте завантажений APK. Android попросить дозволити встановлення з цього джерела; дозвольте для браузера або «Файлів». Під час першого запуску дозвольте сповіщення.

> Всі збірки підписані одним ключем (`app/monitor.jks`), тому нові версії встановлюються поверх старих без втрати налаштувань. Ключ призначений лише для внутрішнього використання; для Google Play потрібен окремий.

## Важливо знати

- **Фонові перевірки** виконує Android WorkManager. На Xiaomi, Huawei, Samsung та подібних телефонах система може «приспати» додаток. Щоб сповіщення приходили вчасно: Налаштування → Додатки → Закупівлі Prozorro → Батарея → **Без обмежень**.
- При першій перевірці додаток лише запам'ятовує поточний стан, тому сповіщення починають приходити з наступної перевірки.
- Джерела даних:
  - `prozorro.gov.ua/api/search` — пошук. Це той самий сервіс, що працює на сайті Prozorro, але він не має офіційної документації. Якщо Prozorro його змінить, пошук треба буде оновити.
  - `public-api.prozorro.gov.ua` — повні дані тендерів (офіційний API).
  - `risks.prozorro.gov.ua` — індикатори ризиків ДАСУ.
  - `audit-api.prozorro.gov.ua` — моніторинги ДАСУ.
- Індикатори ризиків — автоматичні сигнали, а не встановлені порушення.

## Будова проєкту

```
app/src/main/
  assets/            інтерфейс: index.html, style.css, app.js
  java/.../
    MainActivity.kt  екран з WebView, системні відступи, кнопка «Назад»
    Bridge.kt        міст JS ↔ Android (мережа, налаштування, сповіщення)
    Net.kt           HTTP-запити (лише до доменів Prozorro)
    Checker.kt       порівняння стану, пошук змін
    CheckWorker.kt   фонове завдання та планувальник
    Notifier.kt      сповіщення
    Prefs.kt         збереження налаштувань і стану
```

Щоб змінити вигляд або логіку екранів, достатньо правити `assets/app.js` та `style.css`. Інтерфейс можна відкрити і в звичайному браузері.

Мінімальна версія Android — 8.0.
